## 2. Сравнение версий и поиск

- `git diff HEAD~2 HEAD -- lab03/calc.py` показывает построчную разницу между двумя состояниями файла (здесь: что добавилось за два коммита).
- `git show HEAD~1` показывает один коммит целиком: автора, сообщение и его изменения.
- `git log` показывает список коммитов, то есть историю, а не содержимое правок.
- `git log -S"def"` нашёл коммиты, в которых менялось число вхождений слова `def`, то есть где добавлялись функции. Полезно, чтобы найти, когда появился или исчез фрагмент кода.
- `git blame` показал для каждой строки файла, в каком коммите и кем она написана. Нужно, чтобы понять, откуда взялась конкретная строка.
